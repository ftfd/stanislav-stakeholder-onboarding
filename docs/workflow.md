### Linear

* Backlog - still not assigned.
* To Do - issues ready to be processed.
* In Progress - taken issue, work is going on.
* Code Review - issue is waiting to be reviewed.
* Completed - task cheked and approved.
* Canceled - task was dropped.

---

### Git

1. branch - creating new branch.
2. commits - commiting changes with messages of updates.
3. PR (Pull Request) - asking for merging with main.
4. review - reviewing changes by mentor/TL.
5. merge - merging changes to main branch
